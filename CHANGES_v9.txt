=== DonutSMP Plugin v9 — Change Log ===

[Patch: /removebase + minimum spacing between bases, stashes, farms and schematics]

NEW COMMAND  /removebase [preview] [minGap]      (permission: donutsmp.admin)
--------------------------------------------------------------------------
Removes bases that are too close to each other.
  /removebase preview     lists what would be removed, changes nothing
  /removebase             removes them (default min gap = base-spacing.min-gap, 150)
  /removebase 300         same, but treats anything closer than 300 blocks as too close
  /removebase preview 300

Distance is edge-to-edge on the XZ plane (depth is ignored), so a huge base next to a tiny stash is
judged by the gap between their walls, not their centres.

In every cluster the OLDEST placement is kept and the newer ones are removed.
Farms (/spawnfarm) and hand-placed bases (/placeschematicsaround, config fixed-locations) are never
removed, but they still count as neighbours, so a base sitting too close to a farm is the one that goes.

Removing a base: blocks inside its box become stone/deepslate below the natural surface and air above
it (done in slices - config removebase.blocks-per-tick - so there's no lag spike), entities inside are
removed, and it is forgotten by no-mob-spawn zones, StaffWatch base list and geode activity zones.

SPACING FOR GENERATION  (config.yml -> base-spacing)
----------------------------------------------------
  base-spacing:
    enabled: true
    min-gap: 150

  - /placeschematics, /placeschematic: the random spot must keep min-gap blocks from every existing
    base, stash, farm and schematic (size-aware). If the distance band is crowded it retries with 2/3
    then 1/3 of the gap, then reports "Could not find placement" instead of squeezing it in.
  - /generatebases: same check for each procedural base.
  - /spawnfarm and fixed-locations: your chosen spot is always honoured, but you get a warning if it
    is closer than min-gap to something.

NEW FILE  PlacementRegistry.java
--------------------------------
Everything placed is now recorded in plugins/DonutSMPWorld/placements.txt.
On the first start after updating, existing schematics/farms are imported from schematic-zones.txt and
farms.yml so /removebase knows about them.
NOTE: procedural bases (/generatebases) and stashes made by older versions were never recorded, so they
can't be detected or removed by /removebase. Only ones generated from v9 on are tracked.

Other changes
-------------
  LitematicLoader  records each paste in the registry; pasteLitematic(key, loc, kind) overload
  SchematicPlacer  spacing-aware findPlacementLocation (checks spacing before loading chunks)
  BaseGenerator    registers each base's footprint; generateSpreadPositions respects spacing
  StashGenerator   registers each stash
  FarmManager      spawn warning when too close; getPlacedFarms()
  NoSpawnZones / StaffWatcher / ActivityTracker   small helpers so removed bases are fully forgotten
  /donutinfo       shows tracked placement count and spacing
