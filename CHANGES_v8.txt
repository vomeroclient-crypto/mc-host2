POST-PASTE CHEST REFILLING  (LitematicLoader.java)
----------------------------------------------------
LitematicLoader.pasteLitematic() now calls refillChests() after every paste.
It scans the full bounding box of the schematic for Chest block entities and
overwrites their inventories with fresh LootTable.getLoot(meta.lootTier) loot.
This ensures that:
  - The original schematic's chest contents (often empty or test items) are replaced
  - Every server run starts with correctly filled chests regardless of the .litematic file
  - Loot tier is fully controlled from the SCHEMATICS registry in LitematicLoader.java

Logging: "Refilled N chest(s) in <displayName> with '<tier>' loot." is emitted per paste.

LOOT MULTIPLIER  (BaseGenerator.java)
--------------------------------------
Added "regear" → 2.5x multiplier to getLootMultiplier() so procedurally generated
regear-tier rooms get generous loot scaling consistent with their purpose.
